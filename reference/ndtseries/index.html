    NDTSeries¶

    tse.NDTSeries is an N-dimensional series: an N-d array where each dimension has a tse.Axis. An axis is a date range, a list of names, or a plain length, and the axes can come in any order. A TSeries is the one-axis case (dates), and an MVTSeries is the two-axis case (dates, then names).

    NDTSeries is a MATLAB addition. Neither TimeSeriesEcon.jl nor TimeSeriesEconPy has a labelled N-d series. It follows DataEcon's N-d objects, so it can be stored in .daec files.

    Axes¶

    tse.Axis(qq(2020,1):qq(2021,4))   % range axis
tse.Axis(qq(2020,1), 8)           % range axis from a first date and a length
tse.Axis(["gdp" "cpi"])           % names axis (string array or cellstr)
tse.Axis(3)                       % plain axis of length 3

    An axis has kind ("range", "names" or "plain"), length, range (range axes) and names (names axes). labels(ax) gives a label for each position, and describe(ax) gives a one-line summary.

    tse.daec.Axis(...) still works, and returns a tse.Axis.

    Construction¶

    import tse.*
rng = qq(2020,1):qq(2021,4);

x = NDTSeries({rng, ["gdp" "cpi"], 3});           % NaN-filled 8×2×3
x = NDTSeries({rng, ["gdp" "cpi"], 3}, 0);        % filled with 0
x = NDTSeries({rng, ["gdp" "cpi"]}, rand(8, 2));  % values of matching size
x = NDTSeries({rng, 3}, @(sz) randn(sz));         % values from the size
x = NDTSeries('int64', {rng, 3}, 0);              % typed
x = NDTSeries([Axis(["a" "b"]), Axis(rng)]);      % from tse.Axis objects

x = NDTSeries(ts);      % from a TSeries
x = NDTSeries(mvts);    % from an MVTSeries
x = NDTSeries(arr);     % from a tse.daec.Array

    The axes argument is a cell array with one entry per dimension (each entry is anything tse.Axis accepts, or a tse.Axis), a tse.Axis array, or a single MITRange. Values must be numeric or logical, and size(values, k) must equal the length of axis k. The properties axes and values are read-only.

    Shape and axes¶

    Function Result
    size(x), size(x, d), [m, n, ...] = size(x) Axis lengths, like an array
    naxes(x), ndims(x), numel(x), length(x), isempty(x)
    rangeof(x), firstdate(x), lastdate(x), frequencyof(x) Of the date axis; tse.rangeof(x) etc. work too
    timedim(x) Index of the date axis
    names(x), names(x, k) Names of the only names axis, or of axis k
    haskey(x, name) True if any names axis has name; 'dims', k looks on axis k only
    rawdata(x), double(x), isnumeric(x), islogical(x), copy(x)
    permute(x, order) Reorder the axes
    squeeze(x) Drop length-1 axes

    When a series has more than one date axis (for example vintage by date), the date functions need 'dims', k:

    v = NDTSeries({qq(2019,1):qq(2019,4), mm(2020,1):mm(2020,12)});
firstdate(v, 'dims', 2)          % 2020M1
rangeof(v, 'dims', 1, 'drop', 1) % 2019Q2:2019Q4

    Indexing¶

    Give one key per axis. The kind of key depends on the kind of axis:

    Axis Keys
    range an MIT, a step-1 MITRange, consecutive MITs, or :
    names a name (char or string), several names (string array or cellstr), positions, a logical mask, or :
    plain positions, a logical mask, or :

    A single key (one MIT, one name, one position) drops its axis. What is left then decides the result:

    • no axes left: the plain value
    • one date axis: a TSeries
    • a date axis then a names axis: an MVTSeries
    • anything else: an NDTSeries
    x = NDTSeries({qq(2020,1):qq(2020,4), ["gdp" "cpi"], 3}, 0);
x(qq(2020,2), "gdp", 1)     % a number
x(:, "gdp", 1)              % TSeries
x(:, :, 2)                  % MVTSeries
x(:, {'gdp'}, 2)            % a cell keeps the names axis: one-column MVTSeries
x(qq(2020,2):end, :, :)     % NDTSeries, 3x2x3
x.gdp                       % drops the names axis: NDTSeries 4x3

    end is the last date on a date axis and the length on other axes.

    Assignment takes the same keys. The value can be a scalar, an array with the right number of elements, or a series. A TSeries or MVTSeries is lined up on the dates you select. Assigning to dates outside the range grows the date axis and fills the gap with NaN, like a TSeries. Names cannot be added by assignment.

    x(qq(2021,1), "cpi", :) = 1;     % grows the date axis to 2021Q1
x.gdp = 0;
x.gdp(qq(2020,3), 2) = 5;
x.values(1) = 7;                 % values can be set if the size stays the same

    resize(x, rng) changes the date range (with 'dims', k when there are several date axes). find, LinearIndices and isassigned(x, keys...) work as for an MVTSeries.

    Keeping the type when slicing¶

    With tse.setoption('slicing_keeps_type', true), slicing never changes the class. An NDTSeries slice stays an NDTSeries, and an axis given a single key stays, with length 1. An MVTSeries slice (m(mit), m('a'), m(rng, 'a'), m(mit, names)) stays an MVTSeries. In both modes, a single element (x(mit, "gdp", 1), m(mit, 'a')) is the plain value, and dot access (x.gdp, m.a) drops the names axis as above. Use toseries or squeeze to convert explicitly. The default (false) matches Julia and Python.

    Time functions¶

    These work along the date axis and keep every other axis. They take the same arguments as for a TSeries, plus 'dims', k when there are several date axes.

    Function
    shift(x, k), lag(x[, k]), lead(x[, k]) move the dates
    diff(x[, k]) x - lag(x); diff(x, k) as for a TSeries
    pct(x[, shift], 'islog', tf), apct(x[, islog]), ytypct(x) percent changes
    cumsum(x[, d]), cumprod(x[, d]) along the date axis, or axis d
    moving(x, n), moving_average(x, n), moving_sum(x, n) moving windows 
    x = NDTSeries({qq(2020,1):qq(2024,4), ["gdp" "cpi"], 3}, @(sz) rand(sz) + 1);
g = pct(x);                           % 19x2x3, from 2020Q2
v = NDTSeries({yy(2019):yy(2021), mm(2020,1):mm(2020,12)}, 1);
lag(v, 'dims', 2)                     % lag the monthly axis

    Reductions¶

    sum, prod, mean, median, std, var, min, max, any, all and quantile(x, p, ...) reduce over every value by default. With 'dims', d they reduce along axis d, which can be a number, several numbers, or "time" for the date axis. That axis is dropped, and the result is handed back the same way as a slice: a value, a TSeries, an MVTSeries or an NDTSeries. Flags such as 'omitnan', and the weight of std/var (std(x, 1, 'dims', 2)), pass through.

    mean(x, 'dims', "time")      % names x plain NDTSeries of means
sum(x, 'dims', 3)            % an MVTSeries (dates x names)
sum(x, 'dims', [2 3])        % a TSeries

    mapslices(x, f, 'dims', d) applies f to each slice spanning d (default the date axis). A result the same size keeps the axes. A result of length 1 along d drops those axes. Anything else comes back as a plain array.

    Arithmetic¶

    Element-wise operators (+ - .* ./ .\ .^, comparisons, & | ~) and log, exp, abs and unary minus work on an NDTSeries. The other operand can be:

    • a scalar (* and / work with a scalar too)
    • a numeric array of the same size
    • another series whose axes line up: the same kinds in the same order, the same names, the same plain lengths, and the same frequency on date axes

    Date axes are cut to the dates both operands have, as for an MVTSeries. A TSeries or MVTSeries operand counts as the NDTSeries it converts to. Broadcasting a smaller series across the other axes (for example adding a TSeries to every slice) is not supported yet. Comparisons give a logical NDTSeries.

    y = 100 * log(x);
g = x ./ lag(x) - 1;          % dates cut to the overlap
big = x > 10;                 % logical NDTSeries

    Combining and cleaning¶

    Function
    cat(k, a, b, ...) join along axis k: names are joined (and must stay unique), plain lengths add up, and along a date axis each series must start right after the previous one. The other axes must match. [a, b] is an error; use cat.
    rename(x, old, new) rename names on the names axis that holds them; 'dims', k picks the axis, and is required when a name is on more than one names axis
    tse.strip_ts(x) drop leading and trailing dates where every value is missing
    tse.overlay(a, b, ...), tse.overlay(rng, a, b, ...) first non-missing value wins, over the union of the date ranges (or over rng); the other axes must match
    tse.fconvert(F, x, ...) convert the date axis to frequency F with the usual options ('dims', k when there are several date axes)

    Conversion¶

    toseries(x) gives a TSeries for one date axis, and an MVTSeries for a date axis and a names axis (in either order). tse.daec.Array(x) gives the storage form.

    Comparison and display¶

    isequal, isequaln and tse.compare (with 'atol', 'rtol' and 'nans') compare the axes and the values. disp(x) lists the axes and prints 2-d slices labelled by the other axes. It shows at most 5 slices and 40 rows; showall(x) prints everything, and summary(x) prints only the axes.

      8×2×3 NDTSeries of double
    axis 1: range  2020Q1:2021Q4
    axis 2: names  gdp, cpi
    axis 3: plain  1:3
